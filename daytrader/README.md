# daytrader：美股日内交易模型（研究 + 严格验证框架）

## 先说清楚

**没有任何模型能"确保"盈利。** 能做到的是：只用有学术证据的策略，用不作弊的回测，
加上真实成本和防过拟合的统计检验，让一个**没有**优势的策略在花真钱之前就被淘汰。
这个项目就是按这个思路写的：策略 → 回测 → 走步验证 → 7 道关卡 → 才允许纸面交易。

另外：回测里的策略已在随机数据上验证过框架不作弊，**但尚未在真实行情上跑过**
（编写环境无法访问行情数据）。真实结果要你用自己的数据跑出来，可能是不及格。

## 三个策略（都来自公开研究，规则写死，不靠事后挑选）

| 名称 | 来源 | 逻辑 | 持仓 |
|---|---|---|---|
| `orb` 开盘区间突破 | Zarattini, Barbon & Aziz (2024), SSRN 4729284；Crabel (1990) | 每天选相对成交量最大的"热门股"，按开盘 5 分钟 K 线方向，突破开盘区间高/低点入场，止损 0.1×ATR，收盘平仓 | 多只个股，几分钟到全天 |
| `noise` 噪声区间动量 | Zarattini, Aziz & Barbon (2024), SSRN 4824172 | SPY 价格突破"正常波动区间"（过去 14 天同一时刻离开盘的平均偏离）就顺势进场，跌回区间或 VWAP 另一侧就出场 | SPY，日内 |
| `imom` 市场日内动量 | Gao, Han, Li & Zhou (2018, JFE)；Baltussen 等 (2021, JFE) | 昨收到 10:00 的涨跌方向，预测最后半小时方向；15:30 进场，收盘出场 | SPY，30 分钟 |

`ensemble` 把三个放在同一账户里跑，共享杠杆上限和单日止损。

没收录的：均线交叉、RSI、MACD、K 线形态等。它们在扣除成本后的日内学术证据很弱，
加进来只会增加过拟合的机会。

## 防作弊设计

- **没有未来函数**：K 线时间戳是开始时间；信号只用已收盘的 K 线，在下一根开盘成交。
  日线特征（ATR、均量、波动率）只用前一天及以前的数据。
- **保守成交**：止损单若跳空穿过，按开盘价（更差的价格）成交；入场那根 K 线里同时
  碰到止损，算作止损。
- **真实成本**：佣金 $0.0035/股（最低 $0.35）、每边 2bp 滑点、止损单额外 5bp、
  SEC 费、FINRA TAF。
- **风控**：每笔风险 1% 本金（止损型）或日波动目标 1%（波动型）；总杠杆 ≤ 4 倍；
  单只 ≤ 1 倍本金；当日已实现亏损达 3% 就停止开新仓；收盘前全部平仓。
- **自动化测试**（`tests/`）：打乱未来的数据后，过去的交易必须完全不变；在纯随机游走、
  零成本下每个策略的 t 值必须接近 0；在随机游走上必须**过不了**关卡。

## 7 道关卡（全部基于样本外）

走步验证：每次用过去 252 个交易日从参数网格中挑最好的一组，在之后 63 天
（没见过的数据）上交易，把这些样本外片段拼起来再评估：

1. 样本外年化夏普 ≥ 0.75
2. **紧缩夏普比率（DSR）≥ 0.95**：扣除"试了 N 组参数总会有一组好看"的运气
3. 区块自助法夏普 5% 分位 > 0
4. 成本翻倍后夏普仍 > 0
5. ≥ 60% 的样本外窗口赚钱
6. 最大回撤 ≤ 25%
7. ≥ 100 笔交易

**为什么要这么严**：开发时在纯随机数据上跑，零成本下某个策略两年夏普就到了 1.68，
全靠运气。只看回测曲线的话，这种"好策略"会骗过很多人。

DSR 还会惩罚**对参数敏感**的策略：如果网格里不同参数的夏普从 −5 到 +10 都有，
"最好那组"本身就不可信，DSR 会偏低。看 `validate` 输出里的网格，
要的是一片都还不错的"高原"，而不是一个孤立的尖峰。

## 使用

```bash
cd daytrader
pip install -r requirements.txt

python -m daytrader selftest          # 用合成数据确认框架本身没问题
python -m pytest -q tests

# 取数据（Alpaca，需 APCA_API_KEY_ID / APCA_API_SECRET_KEY；完整 SIP 数据需付费）
python -m daytrader fetch --symbols SPY,QQQ --start 2018-01-01 --end 2025-12-31 --out market_data/

python -m daytrader validate --strategy noise --data market_data/
python -m daytrader backtest --strategy noise --data market_data/ --param freq=30 --out trades.csv
```

也可以把自己的数据放进一个目录：每个代码一个 `SPY.csv` / `SPY.parquet`，
列为 `timestamp, open, high, low, close, volume`（不带时区的时间按美东时间处理），
1 分钟或 5 分钟 K 线，复权。

## 数据要求（直接决定结果能不能信）

- **ORB 必须用包含已退市股票的全市场数据**，否则只在"活下来的股票"上选股，
  结果会虚高（幸存者偏差）。Polygon、Databento、Norgate 等提供这类数据，
  免费的 yfinance 只有最近 60 天，不够用。
- 至少 5 年 1 分钟数据，最好覆盖 2020 年 3 月和 2022 年这样的行情。
- 零佣金券商的成本藏在价差里，把 `CostModel.slippage_bps` 调高，而不是只把佣金改成 0。
- SEC 费率每个财年都会调整，用前核对一下 `config.py`。

## 通过关卡之后

1. 纸面交易至少 3 个月，记录每笔的实际成交价，与回测假设的滑点对比。
2. 实际滑点高于假设 → 把实测值填回 `CostModel`，重新验证。
3. 小资金实盘。注意 PDT 规则：保证金账户日内交易需要至少 $25,000。
4. 实盘夏普持续明显低于回测时，停下来，不要加仓。论文里公开的规律会随时间衰减。

本项目仅供研究与学习，不构成投资建议。
